# Viral-Thing
creates prompts based on uploaded videos

## Viral Remix: прототип

Загружаете вирусное видео, получаете его «формулу» (хук, структура, темп, камера, стиль)
и набор коротких промптов для Kling на вашу тему по той же формуле.

## Запуск
1. Откройте `.env` (создаётся из `.env.example` при первом запуске) и выберите, откуда брать Claude:
   - **API** (`REMIX_BACKEND=api`): вставьте `ANTHROPIC_API_KEY`. Подходит, если приложением будут пользоваться другие люди.
   - **Подписка Pro/Max** (`REMIX_BACKEND=subscription`): установите Claude Code CLI
     (`curl -fsSL https://claude.ai/install.sh | bash`) и войдите: `claude auth login`.
     Только для личного использования, запросы тратят лимиты вашей подписки.
2. `./run.sh` → http://localhost:8000

## Как это работает
- `video.py`: PyAV находит склейки (сравнивает соседние кадры), берёт 1–3 ключевых кадра на сцену,
  faster-whisper распознаёт речь (по желанию). Системный ffmpeg не нужен.
- `llm.py`: два запроса к Claude (через API или `claude_cli.py` по подписке, structured outputs):
  1) кадры + таймкоды + речь → формула ролика;
  2) формула + тема → промпты для Kling (1 клип = 1 план = 1 действие, 20–30 слов (максимум 35),
     якорная фраза героя и стиль повторяются дословно, отрицания только в negative prompt).
- Загруженное видео удаляется сразу после анализа.

## Настройка
- `CUT_THRESHOLD` в `video.py`: чувствительность к склейкам (меньше = больше сцен).
- `KLING_SYSTEM` в `llm.py`: правила написания промптов.
